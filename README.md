# Сбор системной информации в Linux

## Описание проекта

`get_all_info.sh` — Bash-скрипт для автоматизированного сбора информации о состоянии операционной системы Linux.

Проект создан в учебных целях для практики работы с командной строкой Linux, Bash, управлением пакетами и системным администрированием. Может использоваться как учебный проект в портфолио начинающего специалиста по информационной безопасности.

## Возможности

Скрипт выполняет следующие действия:

* Проверяет, запущен ли он с правами суперпользователя (`root`).
* Проверяет наличие необходимых пакетов и устанавливает отсутствующие.
* Собирает список установленных пакетов и их версий.
* Сохраняет информацию о запущенных процессах.
* Собирает информацию о прослушиваемых портах и сетевых TCP-соединениях.
* Определяет версию операционной системы и ядра Linux.
* Формирует текстовый отчёт `info`.
* Создаёт архив `OS_RESULT.tar`, содержащий отчёт.

Для демонстрации установки дополнительных пакетов используются `cowsay` и `sl`.

## Используемые технологии

* Bash
* Linux
* APT и DPKG
* `ps`
* `ss`
* `uname`
* `tar`
* Git

## Требования

* Linux на основе Debian, например Kali Linux или Ubuntu.
* Bash.
* Пакетный менеджер APT и система DPKG.
* Права суперпользователя (`root` или `sudo`).
* Подключение к интернету, если требуется установить пакеты.


## Результаты работы

После успешного выполнения в каталоге скрипта создаются:

| Файл            | Назначение                |
| --------------- | ------------------------- |
| `info`          | Текстовый отчёт о системе |
| `OS_RESULT.tar` | Архив с отчётом `info`    |

Проверить содержимое архива можно командой:

```bash
tar -tf OS_RESULT.tar
```

Посмотреть начало отчёта:

```bash
sudo head -n 40 info
```
